# 配置文件与运行实例生命周期

配置复制、重命名、删除使用共享名称校验，拒绝空名称、点、路径分隔符、控制字符以及保留模板名称。模板可以作为复制来源，不能作为复制目标、重命名来源/目标或删除目标。最终路径解析后仍须位于 config 目录，阻止符号链接指向目录外的文件。

重命名、删除入口在停止任务前校验名称、来源和目标。运行实例标记 retiring 后拒绝再次启动；等待 stop 完成，再修改文件并移除管理记录。重复操作返回 409。停止或文件操作失败时保留实例记录并解除 retiring，避免仍存活的任务失去管理入口。stop 在终止子进程后在线程中等待退出，最多 10 秒；超时保留进程引用和原状态并报告错误，不伪报停止成功。

后台推送每轮按当前配置实例的身份整理日志/状态协程。配置移除、同名替换时取消旧协程并等待清理，为新实例创建推送协程；意外结束的协程也可重建。数据线程退出时清理其持有的全部协程。此改动不调整前端 WebSocket 重连策略。
