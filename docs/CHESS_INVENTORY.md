# 百鬼棋局持有量、星级及棋盘身份

## 规则与配置

铜色勾玉为一星、银色为二星、金色为三星。三张一星合成一张二星，
三张二星合成一张三星；一、二、三星分别折算1、3、9张一星。
实际卡片数与折算张数分开记录，不以历史累计购买数冒充当前持有量。

所有既有阵容默认追三星。新阵容可在 `shikigami_positions` 内使用字典格式：

```python
'薰': {'weight': 1, 'position': 2, 'souls': ('魍魉之匣',), 'target_star': 2},
'白狼': {'weight': 1, 'position': 4, 'target_star': 3},
```

`target_star` 只接受整数1、2、3，省略默认3。旧站位及御魂元组继续兼容，
不要把目标星级写入旧四元组的守护之印字段。本次没有新增前端配置入口。

## 持有量与购买、出售

每回目首次确认进入备阶段且商店收起后，读取一遍棋盘的12格位置和勾玉星级，
已确认的式神名称按位置复用。之后由确认的上阵、下阵、出售、合成和
金鱼换位更新棋盘。备战区与商店分别按需要识别，备阶段不会重复
输出整盘持有快照。账本驻留内存，每局重建。

购买量按同名式神的场上星级折算值（1、3、9）加备战区实体张数计算，
备战区每张计1。已有足够的实际达标成品时停止购买。购买确认后重新
读取手牌，并仅核对可能合成的同名场上单位。未知棋盘身份不阻塞其他
目标的交易，买入结果不明时本回目不再次购买同名卡。

已达到目标的多余同名卡仍按实际星级和数量保护。仅有足量材料时不当作
已合成；出售需稳定新帧确认对应手牌恰好少一张。五阶前通常只观察手牌，反击姑获鸟可提前上阵。五阶起处理装备和手牌清理。手牌及棋盘出售还要求
进入第4回目，
河童等过渡卡遵守各自的替换和出售规则。

## 棋盘挡位处理

备阶段先尝试上阵和装备。仅在手里有可上阵的阵容卡，并且目标格被占或
人口已满时，才检查挡位的未知单位。点击棋子打开详情，两帧确认完整式神名后与阵容和替补名单比对。
不在名单中的单位通过详情的“出售”文字按钮直接出售，两张新帧确认原格
连续为空才释放占位。若动画超出确认时间，下回目正常扫盘时再核对该格。
金鱼、名称或按钮未确认的单位会保留。

挡在目标格、却应配置到其他站位的阵容牌先下阵，再从重排后的手牌识别
并按指定站位安排上阵。回收要求原格清空及备战区星级折算量增加。场上
低星且有同名高星手牌时，仍可先换下低星。已确认站在正确位置的阵容牌保留。

没有适用的补阵、装备或腾位操作时，按当前阶数、金币、阵容需求继续判断
经验及商店刷新。战、待阶段沿用现有经济与手牌清理权限，鬼阶段不发起
经济操作。新操作检查阶段、回目、符咒面板和末3秒截止，保留设备卡死检测。

## 缺少人物素材的非阵容手牌

星级勾玉可独立定位缺人物素材的普通式神手牌。未知记录使用完整卡框
及卡片中心，不能用勾玉所在的1×1区域做阵容保护或直接拖动。
库存核对/商店手牌刷新遇到这类卡时，先排除低阈值多尺度阵容模板
（包括河童替补）、御魂、守护之印、纹章、发现御魂/纹章等特殊牌；
只有可排除上述类型的普通式神卡才出售。勾玉匹配至少0.88且与其他
星级拉开0.12分时，可直接确认普通式神类型，跳过整套御魂/OCR扫描；
阵容和替补保护先执行。若低阈值保护命中相似头像，只有在识别到星级勾玉且
非阵容卡面明显胜出时才解除保护。
连续三帧确认星级、手牌数量、位置及卡面稳定，耗时识别后出售前
重新检查阶段、回目和同一卡面。刚完成的两帧稳定手牌可直接作为前
两帧证据，仅补一帧，不从零再等三帧。
出售后以两帧手牌签名确认恰好少一张；失败不重拖、不将库存记为就绪。
同一卡面重复确认不重复执行昂贵的全套装备/OCR保护。

同一截图、同一回目和阶段、0.7秒内的两帧稳定手牌可复用。买牌、
出售、部署、回收及装备拖动前作废观察，换帧或超时不复用坐标。

## 验证与限制

`dev_tools.test_chess_inventory` 覆盖场上星级与手牌混合计数、购入上限、赠送多余卡、
成品与材料保护、未知状态、交易未确认、直接出售、阵容挡位回收、阶段/回目中断、
默认与自定义星级，以及金鱼与普通单位的区分及换位记录。
与原棋局商店、运行安全、闲时、退出、任务/服务启动测试共同回归。
`dev_tools.test_chess_unlisted_hand` 覆盖缺素材清理后恢复河童购买、
前三回目保留与第4回目恢复清理、替补和装备保护、卡面/位置/阶段变化及未确认交易。
`dev_tools.test_chess_action_priority` 覆盖装备解锁、同帧观察作废/过期、
回收原格确认、优先清理和快照后不重复扫描。

星级识别复用现有铜/银/金勾玉素材，手牌按缩放匹配。用户提供的真实

实战确认不同动画、遮挡和卡片重排下的稳定性。没有启动游戏。
