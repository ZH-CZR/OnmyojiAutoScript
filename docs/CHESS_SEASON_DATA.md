当前生效目录为 `tasks/Chess/strategy/shikigami_catalog.py`；根目录的
`tasks/Chess/shikigami_catalog.py` 仅兼容转发，避免维护两份不同数据。

## 六道之门赛季修正

- 山童：2费改1费。
- 夜叉、山风、久次良、御馔津：3费改2费。
- 久次良：锻刃改回响；河童、荒川之主：分裂改回响。
- 古笼火、云间不见岳、梦山白藏主、御馔津：甲胄改遗念。
- 白狼：嗜战改追击；小松丸：嗜战改分裂；管狐：护佑改甲胄。
- 平将门：异形改常世。

费用变化同步修正商店购买能力、反击阵容的支出记账及费用＋羁绊签名。
新费用编号只追加，不复用旧编号；旧 `2-1`、`3-5`、`3-7`、`3-10`、
`3-14` 通过 `resolve_shikigami()` 及阵容转换接口仍解析为原式神。
素材文件继续按罗马音命名，不因费用改变重命名。

依据为用户提供的游戏截图与[赛季更新记录](https://yys.huijiwiki.com/wiki/百鬼棋局)。
更新记录为社区资料，不将其表述为逐张游戏内实测；截图能直接核对的
项目与其余数据来源记录在 `upstream/chess_season_20261021.json`。

## 文字变化是否影响模板

商店模板主要裁取头像，名字和羁绊另有 OCR。手牌模板包含部分羁绊
文字，文字变化会降低匹配分数，因此另用用户新截图离线回放核对。
本轮没有修改图片素材，也没有降低阈值。

| 新截图中的卡 | 原模板匹配分数 | 使用阈值 |
| --- | ---: | ---: |
| 山童商店 | 0.9752 | 0.75 |
| 古笼火商店 | 0.9927 | 0.75 |
| 河童商店 | 0.9891 | 0.75 |
| 觉商店 | 0.9985 | 0.75 |
| 妖狐商店 | 0.9815 | 0.75 |
| 河童手牌（分裂变回响） | 0.9481 | 0.75 |

河童买入后新截图不再在商店命中，手牌分类和星级账本确认一张一星
河童。以上样本没有因文字变化漏识别；没有这些新卡面截图的其他
式神尚未逐张实测，不能据此声称全部皮肤和所有动态光效均已验证。

OCR 仍按名字、羁绊及费用、头像兜底的顺序执行。修改后的共同羁绊
若对应多张式神，必须用费用消歧，失败才转头像，不凭残缺羁绊猜卡。
新增 `dev_tools.test_chess_season` 验证当前费用、羁绊签名、旧编号兼容、
菜单一致性和真实 OCR 调用链；装备与优先级见
`dev_tools.test_chess_counter_ubume`。不启动游戏，不保存完整用户截图。
