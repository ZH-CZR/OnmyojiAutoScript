# 百鬼棋局商店确认

棋局商店使用独立的 `I_CHESS_SHOP_REFRESH`，不可使用 `self.I_REFRESH`：
完整任务继承链会将后者解析为 `GameUiAssets` 的公共导航刷新图标，
导致商店虽然展开却持续报告按钮缺失，经济序列停在刷新步骤，金币不断积累。
回归必须通过完整 `ScriptTask` 检查素材解析，不能仅测试 `ChessAssets`。

经验按当前经验与升阶所需经验之差计算，每次增加4经验、花费4金币。
同一批最多买到本阶升阶线，同时受阵容序列和金币底线约束。批次内检查
阶段和回目，连续点击完毕后统一确认总扣款。确认升阶后重新判断买经验或刷新。
1～2 阶只买经验；3～7 阶按“经验、经验、刷新”循环；8 阶起未达目标时
按“经验、经验、刷新、刷新”循环。达到阵容目标阶数后只刷新。
升级改变阶数时按新阶数重置序列；预算不足、阶段切换或结果未确认可在两次经验之间停止。
保留金币仍为 1～2 阶 0、3～5 阶 35、6～7 阶 23、更高未达目标时 10，
达到目标后为 0。

## 所有阵容通用的阶段优先级

每回目首次确认进入备阶段且商店收起后识别一次棋盘，后续上阵、回收、出售和升星更新相应位置。
备阶段独立识别手牌，先将当前阶数允许的阵容牌放到指定位置，再按装备
优先级上装备并清理非阵容手牌。目标格被占或人口已满时，才打开挡位
未知单位的详情确认身份。阵容外单位在详情直接出售，错位阵容牌按指定
站位重新上阵。没有适用动作时按阵容运营节奏升级或刷新。上阵或装备
关闭商店后，继续买下一张前重新确认展开。详见 `CHESS_INVENTORY.md`。

装备流程统一延后：至少六阶，且当前阶数允许的每种阵容角色至少持有
一张（棋盘或备战区均可、替补可满足对应角色），才解锁御魂、纹章、
守护之印和发现卡使用。解锁前保留装备，不做昂贵的装配扫描；解锁后
本局不因升阶增加新角色而反复冻结，换阵容/新局重新判断。

备阶段先处理上阵和装备，再清理非阵容手牌。装备尚未解锁时保留装备和纹章。

战阶段先确认商店展开并购买当前商店的阵容牌，再清理手牌并按最新
余额判断经验或刷新。识别不到安全可买的牌时，仍可按经验预算执行。
待阶段沿用符合条件先买经验、再检查自然商店的顺序。战、待阶段
不做部署/装备。战转待会重新评估经济，不沿用战阶段的“预算已完成”
标记；已确认扣款后进入新阶段，可采用该阶段结算收入更新后的金币。
未确认经验仍锁定本回目，刷新未确认仍锁定本局，不能借阶段切换重复点。

上述顺序是所有现有及后续注册阵容的共用规则，手动/定时/闲时一致；
每个阵容的金币底线、升级条件、追星目标和经验/刷新序列保持独立。
反击姑获鸟的预算和阶段门槛见 `CHESS_COUNTER_UBUME.md`，不套用上面的默认预算。

备、战、待及鬼阶段剩余3秒及以下不发起新操作；倒计时不明也暂停普通
局内操作，继续截图等待下一阶段。上阵、装备、卖卡、商店开关、购牌、
经验、刷新均在实际下发前检查；已经点击的交易继续只读确认，避免因
临近阶段结束误记账或补点。下阵和特殊详情仍保留更长的操作安全余量。
符咒面板可读到倒计时不大于3时也停止刷新/选择，面板遮挡倒计时时
保留原弹窗处理流程。
保留设备卡死检测；两种经济循环均有独立300秒无阶段进展总超时，
作息/活动限制的主动休息时间不计入超时。

战阶段临时开店失败、按钮遮挡或 OCR 失败返回 blocked，不再视为本回目经济完成。
备、战、待阶段的运营暂时受阻时，外层间隔至少3秒重试并重新读取回目和阶段。
已点击但结果未明的交易仍受原有防重复保护。反击姑获鸟只为已发出点击的买牌预留金币。
首次购买同样使用战阶段开店确认，未确认展开时不扫描卡片或刷新。

战阶段不能仅凭 `_shop_assumed_open` 或点击商店成功返回就继续读卡、刷新。
`I_CHECK_MARKET` 在商店收起时也可能出现，不作为展开确认。
开店以刷新按钮或金币不足刷新标志为准；战阶段先等待一张新截图，
若仍未确认则只点击一次商店，并在最多 8 秒内等待展开标志。
超时或阶段切换后停止当前购买和刷新，避免反复开关。

备、战阶段的刷新均要求当前帧可见可用刷新按钮，不能因战斗特效遮挡而盲点。
刷新按钮短暂不可见时最多检查3帧（间隔0.35秒），恢复后才允许点击；
持续失败记录阶段和模板分数，鬼阶段中断单独记录，不再误报为按钮缺失。
刷新后商店不可见时不扫描棋盘区域；买卡后商店不可见时，不能把卡片消失当作购买成功。
保留原设备卡死检测，未改变刷新坐标、经济预算或闲时目标。

P0 交易保护（2026-10-28）：每次刷新只点击一次，在同一回合、同一阶段以
两张稳定新帧及扣款或任意槽位变化确认。不再要求至少三格变化；结果未明时
本回目停止付费刷新，确认进入新回目后才重新检查商店。
全同名回刷需要扣款证据；仅扣款而画面不稳定也不能开始买卡。

商店只匹配当前阵容及替补的卡面图像，保留原灰度发光图像兜底，不调用名称或羁绊 OCR。
费用由赛季目录提供；未匹配的槽位显示“未匹配目标卡”，不识别全目录非目标牌。
旧 OCR 诊断方法保留，但购买、摘要及刷新确认均不调用。
同一帧的槽位图像结果复用，帧号或截图对象变化后重新匹配；阵容切换清空缓存。
目标图像明确且金币可负担才单次点击；同回目/阶段、商店可见、金币恰好减少
卡牌费用并且目标图像消失，才确认购买。漏识别但没有扣款证据不能记成功；
未确认不补点、不出售阵容材料，停止本轮购买和刷新。数字 OCR 保留。
星级持有上限与达标后的多余卡清理见 `CHESS_INVENTORY.md`。

前三回目保留手牌和棋盘单位，第4回目起恢复出售。普通式神即使缺少人物素材，也可
先按勾玉定位、排除当前阵容及特殊卡后确认出售，再核对库存、继续买牌。
不能让一张缺素材的非阵容手牌使整轮商店永远无法扫描；详情及截图
回放见 `CHESS_INVENTORY.md`、`dev_tools.test_chess_unlisted_hand`。
