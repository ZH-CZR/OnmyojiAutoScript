# 庭院入口交叉定位

庭院仍使用 `I_PAGE_MAIN_RELAX`、`I_WQ_DONE`、`I_WQ_SEAL` 任一命中作为页面判定。
本次不增删入口图片、不修改生成的素材定义和用户配置。正常路径仍优先匹配目标入口，点击后确认目标页。

## 兜底流程

- 仅适用于从庭院进入探索、町中、召唤和宠物屋；该轮所有直接入口操作都未成功点击时才尝试。
- `tasks/GameUi/page.py` 初始化入口目录，保存各素材原始 `roi_front`，按默认皮肤或数字后缀分组；`_14_1` 等动画变体归入皮肤 `14`。
- 在其他入口原始位置附近匹配，扩展 16 像素（公共裁剪另有 5 像素边距），最低阈值 0.85。识别使用独立副本，不依赖匹配后被改写的共享坐标。
- 同一皮肤同一入口的多个变体只算一项证据。只有一个皮肤命中时可作为候选；有多个皮肤时，候选必须有更多独立入口支持，同票则放弃。即使竞争皮肤缺少目标入口，也保留它参与冲突判定。
- 两次新截图间隔 0.35 秒，每次重新确认庭院、检查已知确认/取消/登录卷轴遮挡，并要求推断结果一致。不跨帧段或跨导航缓存皮肤和坐标。
- 点击原始目标区域中心，等待最多 6 秒识别目标页；确认成功才更新导航状态。单次 `ui_goto` 对每种入口最多兜底点击 3 次，继续遵守整体导航超时及设备原有卡死检测。

## 边界

固定区域兜底要求 1280×720 截图、固定庭院视角，以及明确的入口坐标。没有足够证据时继续原导航重试与超时处理，不按皮肤顺序盲点。

旧素材中部分 `roi_front` 记录为宽大的搜索范围，例如绮梦茨庭（`main14`）入口、暖池青苑（`main6`）宠物屋。
宽或高超过 100 像素、越出屏幕、同一皮肤目标变体区域不一致时，不使用固定区域点击，保留原图像识别路径。
该尺寸上限为保守保护条件，不代表其他记录已完成游戏内点击校准。
枫色秋庭（`main5`）宠物屋虽保留历史素材，按现有功能说明排除固定区域兜底。

共用庭院标记不能证明整个画面都无遮挡；已知弹窗检查也不覆盖所有游戏弹窗。拖动庭院、其他遮挡或皮肤间近似素材仍可能影响结果。
离线测试只能验证匹配规则和导航控制，不能证明所有皮肤的实际点击准确率。没有进行游戏内操作。
