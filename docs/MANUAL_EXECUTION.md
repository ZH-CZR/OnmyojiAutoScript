# 手动执行

所有带调度器的任务可选择“定时执行”“闲时执行”“手动执行”，默认仍为定时执行。
手动模式需要开启任务开关，配置处于启动状态后，仅由前端“立即执行”（含用户点击的“全部立即执行”）提交的一次性请求运行。
配置停止时点击可先排队，启动配置后执行；仅启动配置、修改任务时间、任务回调或成功/失败延后均不触发手动任务。

手动模式隐藏调度时间、优先级、成功/失败间隔、随机延迟、闲时目标与余量，以及任务专用的宴会日期、道馆周末跳过和青蛙瓷器提前执行时间。隐藏值保留，切回原模式恢复。总览显示“等待手动执行”，隐藏时间编辑与“立即等待”，保留“立即执行”。

请求通过 `POST /{script_name}/{task}/run_now` 提交（前缀沿用服务端路由注册），以忽略文件 `config/activity/manual.sqlite3` 在服务端与任务子进程间共享，按配置和任务隔离。排队期间重复点击合并，实际运行前原子消费选中的令牌；准备环境要求重新调度时保留请求，任务已开始后即使异常也不自动重跑。任务运行中新增请求使用新令牌，不被旧运行清除。显式停止配置、切换执行模式或任务开关、成功删除或重命名配置会清理未执行请求。

手动请求优先于普通到期任务，当前任务不被强行中断；闲时任务在原有结算检查点清理后让位。执行时忽略旧 next_run、日期与时间窗口、失败冷却和随机延迟，也跳过作息、每日运行上限及连续任务休息等待；运行耗时仍按原规则累计，后续自动任务继续遵守作息。运行时的游戏启动与恢复也复用此次手动请求的免等待语义。

已取消手动模式的活动入口时间拦截：狭间暗域、首领退治、狩猎战、逢魔、地域鬼王、斗技、道馆、宴会、神秘商店；狩猎战仍按当天选择麒麟或阴界。棋局手动请求可绕过本周停刷期限，但不删除停刷记录，切回自动模式继续生效。任务内部的高优先级自动让位不打断手动任务。

次数、单次运行时长、体力/门票/满币等业务条件、QQ消息条件、界面等待超时及卡死检测仍生效。手动模式不会让游戏实际关闭的活动开放，也不伪造停服、识别或领奖成功。错误恢复保持原机制，失败任务本身须重新点击才再次运行。

验证：`dev_tools.test_manual_schedule` 覆盖排队、隔离、一次性消费、失败不重跑、模式切换、接口与可见性、动态加载及作息绕过；同时运行现有调度、闲时、入口与启动回归。前端运行 `test/args_test.dart`、`test/idle_args_test.dart`、`test/manual_api_test.dart` 及静态分析。均为离线验证，未操作游戏或真实设备。
