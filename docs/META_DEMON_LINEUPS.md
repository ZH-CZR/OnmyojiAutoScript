# 超鬼王统一阵容与特定鬼王进攻

2026-11-11，在现有独立超鬼王任务上重构；此前 YYS 素材及合成逻辑继续保留。

## 前端设置

配套 OASX 的超鬼王页面只显示一个“鬼王阵容”模块。开启“切换御魂”，分别填写
一至四星、五星和六星的通用阵容，格式为 `分组名,队伍名`。御魂和预设使用同一阵容字段，
勾选“同时切换预设”后，直接在挑战页右侧队伍面板选择预设并点“出战”；
若出现“御魂不一致，是否自动装配御魂并出战”弹窗，点击“确定”一起完成御魂装配，
不再重复进入式神录。未勾选时才单独进入式神录换魂。预设必须使用游戏中的实际组名和队名。
旧数字 `组号,队号` 仍用于御魂序号切换；要使用新挑战页预设，请改填实际名称。

“新增特定鬼王”可添加多个条目，每条填写完整鬼王名称、一次或两次进攻。
每次进攻独立设置阵容、普通/强力追击、是否标记主怪。选择一次时仅显示第一套；
切换回两次时保留之前编辑的第二套。阵容留空沿用该星级通用阵容。
名称精确匹配，重复名、空名称、非法进攻次数和非法阵容格式不能保存。
草稿模式支持统一保存/取消；结构化列表作为一个参数保存，避免逐项增删的中间状态写盘。
即时模式中未填完整的新条目只留在编辑器内，填写有效后才发送保存请求。

## 运行规则

- 每次实际挑战前选择本次进攻配置；特定鬼王优先于星级通用配置。
- 与上次已确认挑战阵容相同则跳过换魂；变化时按勾选项选择“预设自动装配御魂”或“式神录单独换魂”其中一条路线。
  攻击方式和标记开关变化不触发重复换魂。同阵容跨鬼王可复用，但不能跨任务运行复用。
- 式神录路线只在御魂装配确认实际点击、弹窗消失且返回挑战页后更新缓存；
  预设路线兼容无弹窗，出现自动装配弹窗时最多确认3次，随后只观察不续点；
  统一在15秒结果等待期限内确认弹窗和面板均关闭、挑战页与目标队名连续稳定至少0.35秒后才记成功。
  御魂装配未确认不能重复点击“出战”。任一步失败均作废缓存并报错。临时 OCR 规则用实例副本，退出恢复。
  不使用公共 SwitchSoul 提前写入的缓存；自身换魂使该公共旧缓存失效，避免污染后续任务。
- 一次进攻仍存活时停止本轮并保留鬼王。两次进攻依次使用第一套、第二套；
  第二次后仍存活，按用户要求用第二套的阵容、强力/普通及标记设置补打一次。
  第三次后仍存活则停止本轮，不无限补打。若提前击败，不执行剩余进攻。
- 进攻次数只在确认进入战斗并完成战斗等待后推进；点击挑战失败不消耗进攻序号。
  只有实际确认新召唤后才重置本只鬼王计数，同星同名连续鬼王也独立计数。
- 未匹配特定鬼王时按当前疲劳选票规则及原星级强力列表运行，保留原总次数、运行时间及疲劳限制。
  数量上限可能在两次进攻之间结束任务，不为凑齐配置次数突破上限。
- 每次阵容切换固定120秒总限时，原入口、选票、合成、战斗结算总时限和设备卡死检测保留。
  `run()` 的 finally 仍恢复全局导航；不支持跨进程重启续接某只鬼王的进攻序号。

## 配置兼容与接口

新组为 `meta_demon.lineup_config`，字段为 `enable`、`preset_enable`、`common_stars`、
`five_stars`、`six_stars`、`specific_bosses`。每条特定鬼王包含 `boss_name`、`attack_count`、
`first_attack` 和 `second_attack`；每次进攻包含 `lineup`、`powerful`、`mark_main`。

旧 `switch_soul`、`preset_switch` 继续兼容读取及保留，但不再显示为独立表单模块，运行入口
统一走新计划。已有显式新字段优先；旧预设启用时优先迁移其名称映射和星级配置，否则迁移御魂配置。
旧的一至四星若配置不同，通过隐藏的 `legacy_stars` 保留，填写并保存新通用阵容后清除。
迁移只发生在模型读取，不自动写用户配置；增量保存生成不完整新组时，缺失字段仍继承旧配置，
不能因首次只保存特定鬼王而意外关闭换魂或丢失旧阵容。

`/args` 用 `meta_demon_bosses` 类型提供完整条目列表，仍经现有单参数保存接口传输 JSON 字符串，
服务端先解析列表，再经模型校验和既有增量保存/文件锁写入。未新增管理配置文件或独立数据库。
