# 地域鬼王数量统计

`boss_number` 表示本轮完成挑战的鬼王数量，默认三个；悬赏鬼王包含在该数量中。
通用 `current_count` 仍用于记录战斗场次，不能用作鬼王数量：同一悬赏鬼王可能先打普通60级，再打极地鬼，产生两场战斗。

任务独立累计完整挑战成功的鬼王数量。已获得小组排名的候选跳过，不重复计入本轮数量；无法打开详情、战斗失败也不计入。悬赏与热门候选重合时，继续检查后面的候选。

候选范围仍为热门或收藏的前三项，不会自动选择其他鬼王。候选已挑战、未解锁或战斗失败导致不足时，通知报告实际完成数量；已在本轮之前打过的鬼王不算本轮新增数量。

离线验证（不启动游戏）：

```powershell
.venv\Scripts\python.exe -m unittest dev_tools.test_area_boss dev_tools.test_task_startup dev_tools.test_server_startup -q
```

覆盖普通60级解锁后再打极地鬼、悬赏与热门重复、失败通知、默认三个和自定义数量。离线通过不代表游戏内识别或战斗流程已实测。
