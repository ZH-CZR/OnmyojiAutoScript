# 自己发现鬼王结算时检查好友

自己发现的鬼王结束战斗/奖励画面后，如果详情显示“结算中”且左侧有好友卡片，
立即检查好友助战，不等自己的鬼王完成结算。挑战按钮、自己发现卡框及旧入口
标志都不是前提：结算期间这些入口可能同时隐藏或位置变化。尚在战斗或领奖时
不提前点击好友。

确认离开战斗后识别到结算文字，即在本次战后300秒流程内保留该状态；好友卡片
随后出现时也立即检查，不要求结算文字与好友计时条在同一帧。没有好友计时条
时保持原等待，不能点击“暂无好友发现鬼王”的空白区域。不跨战斗保存该状态。

检查复用原好友头像白名单、排除结算条目、星级/名称及阵容/预设流程。
有合格目标时直接切换，自己的最后一次进攻不计入新好友的次数；没有合格目标
时返回自己发现并继续原来的300秒结算总时限，同一轮不重复打开已检查的条目。
自己的卡片已被鬼王头像占用时，不再依赖空卡图标，使用用户指定的自己发现区域，
仍保持最多3次点击、2秒间隔及15秒返回总时限。选中金框确认返回，中央玩家头像
可能与好友头像相同，不能因此拒绝已经确认的自己发现页面。

疲劳超过70插入的单只最高星召唤战，也可在详情结算时直接交还原助战恢复流程。
该路径只恢复之前保存的好友卡片及进攻次数，不任意替换目标；结算中暂不打开
队列探测余票，清除余票已检查标记，下次按原规则重新读取。

实现位于tasks/MetaDemon/script_task.py、friend_assist.py及ticket_priority.py。
回归dev_tools.test_meta_demon_own_settlement覆盖立即检查、隐藏挑战按钮、战斗及
奖励保护、无好友/无合格目标继续等待、新旧进攻次数隔离、返回有鬼王的自己发现、
检测标记清理和插入召唤后的原助战恢复。未启动游戏，实际切换响应仍待实测。

验证：新增12项用例；工作树相关431项回归中429项通过、2项跳过。独立加载实际
暂存源码后的145项测试全部通过，确保本次修改不依赖其他未提交的预设/点击改动。
