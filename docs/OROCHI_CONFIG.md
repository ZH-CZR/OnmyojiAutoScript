# 八岐大蛇配置

“御魂任务”保留旧内部字段名 `next_day_orochi_config`，避免破坏历史配置。

- “御魂任务选择”只用于快捷填写挑战层数和限制挑战次数，选项为“不选择”、拾层30次、悲鸣30次、神罚50次、神罚120次。
- 新配置默认“不选择”，运行时直接使用下方层数、次数；仍同时受限制时间约束。
- 在配置保存接口中选择预设，会一起保存对应层数和次数。手动编辑层数或次数时自动切回“不选择”。重新获取任务配置即可得到全部更新后的字段。
- 旧固定预设在加载时落实为对应层数和次数。旧“无限循环”“只执行一次下面的配置”“本次不执行，设置明天运行(拾层-30)”迁移为“不选择”，保留自定义层数和次数；旧跳过选项不再具有跳过本轮的作用，需要暂停任务时使用调度器开关。
- 计划不再指定次日时间，成功和失败统一交给通用调度器。原“启动时间”隐藏并仅用于迁移：调度器缺少 `server_update` 时沿用旧值；已有显式字段（包括09:00）始终保留。
- 调度器 `next_run` 是本次排队执行时间；`server_update` 是任务完成后计算后续执行时间的设置。沿用通用规则：09:00使用成功/失败间隔，其他时间按强制日期间隔安排并叠加随机延迟。这两个调度字段用途不同。
- 更换御魂按最终挑战层数选择方案，壹至玖层没有专用方案时不调用切换。
- 宠物喂养启用“是否执行一次御魂”时，固定挑战拾层一次；换御魂沿用八岐大蛇的切换开关和“魂十切换御魂”方案，不使用真蛇方案。
- 宠物魂十战斗返回后继续截图处理延迟出现的“发现宝藏”和普通奖励，确认挑战按钮稳定出现至少1秒后才结束任务，避免奖励弹窗挡住下一任务。结算等待最多30秒，超时在宠物任务内抛出卡死异常，不交接到下一任务；保留设备卡死检测。
