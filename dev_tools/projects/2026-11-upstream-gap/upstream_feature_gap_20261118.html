4. 本地缺的新功能（按性价比）

P1起号套件（kongdr 4 个任务）

组成：AutoStory · ExplorationFight · BorrowShikigami · CustomTask（lgg686 无独立 BorrowShikigami）

能力：自动过剧情 → 借用式神 → 探索推进 → 经验妖怪，循环直到账号 15 级；兼容新手弹窗与新手战斗页。

依据：547dfba6 3a8ba22f fc45a500 628c0cfb 80751206

风险：与本地 base_task 耦合浅，移植成本低，功能面增益最大。

P1协同对弈 DraftDuel（最大单项缺口）

规模：kongdr 70 个文件 / lgg686 121 个文件（2026-10-30 起）

能力：大厅消耗识别、邀请好友、队长/队员双端、自动选人（阵容矩阵评分 + 火系名单）、训练模型介入、真实对局记录、上阵拖拽。

可复用：本地已有 module/team_flow（MQTT）可承载双实例协同。

风险：开放时段限制、头像识别阈值、双端时序；高投入高收益。

P2绘卷查询 module/scrolls

来源：kongdr，20 个文件（依据 95b75dd8 92ada2c7）

能力：官方资源解析 + 绘卷进度 / 排行榜 / 碎片库存查询，适配 Linux 与 redroid。

定位：查询工具而非自动化任务，需 cryptography 等依赖，按需评估。

P3武道大会首领战（已进 staging）

差异：本地门票 pass + 体力 ap；lgg686 MartialArts 额外有首领 boss（boss_limit，run_sequence 可配）。

现状：staging/20261120-mt-boss 已完成移植，自动化 5 passed、全量 520/10（均为既有失败），待武道大会开放后实机验收。

结论：不另建批次，实机通过后按合并闸门合入 czr。
