# 购买寮包

独立日常任务，位于“日常任务 → 购买寮包”，默认关闭。使用项目公共调度配置，每日执行间隔、更新时间、优先级和下次运行时间可以单独设置。

流程：公共导航进入神社 → 寮内采办 → 识别阴阳寮礼包 → 识别并点击最大上限 → 等数量稳定 → 识别并点击功勋购买按钮一次 → 验证结果 → 关闭礼包窗口、返回神社 → 设置下次执行时间。

成功依据为奖励界面、购买成功提示，或购买窗口关闭且寮内采办页面中的功勋余额减少。识别到购买上限会跳过，识别到资源或权限不足会记录失败。导航、找图、数量识别及结果等待均有超时；结果不明不会重复点击购买，并保存任务截图。实际购买权限仍由游戏决定，参考截图提示仅会长和副会长可购买。

资源来自用户提供的 E:/oas/Screenshots。商品、最大上限及购买按钮均按图片匹配位置点击；购买按钮模板选取内部功勋图标，搜索区域覆盖数量改变后图标的横向移动。购买窗口标题用于确认商品身份。图片、提示和 OCR 坐标按 1280×720 游戏截图布局设置。

更新规则后用项目自带 Python 生成本任务的 assets.py：

```powershell
.\toolkit\python.exe -c "from dev_tools.assets_extract import AssetsExtractor; AssetsExtractor('./tasks/GuildGift').extract()"
```

离线验证：

```powershell
.\toolkit\python.exe -m unittest discover -s tests -p test_guild_gift.py
```
